# BA Generate UI Styleguide

## Use when

- The project has specific branding guidelines, colors, or visual preferences.
- You want the screens generated by other skills to use a consistent design system.
- You want to automate the creation of design guidelines instead of writing them manually.

## Do not use when

- The project uses a completely custom, private Figma library that cannot be mapped to standard AI components.
- No client-specific design constraints are defined yet (use system defaults in that case).

## Inputs

- Brand guidelines, logo descriptions, colors (hex/rgb), legacy system text, or general UI instructions.
- Target device type (Web desktop, iOS, Android).

## Instructions

1. Parse the input and extract key visual styles:
   - Primary, secondary, and accent colors. Convert these to HSL formats (which Figma Make prefers).
   - Layout parameters (e.g., standard margins, vertical split layout, grid columns).
   - Border radius rules (e.g., sharp 4px, rounded 8px, extreme pill corners).
   - Component style guides (e.g., how buttons should look, form inputs spacing).
2. Generate the design rules and save them as a project-specific guide (`figma-make-guidelines.md`).
3. Ensure all generated guidelines use standard Figma Make AI component vocabulary.
4. Structure the output into clear categories: Layout, Typography, Colors, Components, and States.

## Output

- `figma-make-guidelines.md` (Project-specific UI rules saved to the workspace for downstream screen generators to consume)

## Supporting files

- `shared/figma-layout-guidelines.md` (Base baseline rules)
- `shared/figma-component-guidelines.md` (Base component mappings)
- `shared/extraction-rules.md`
