# Figma MCP: Layout Guidelines

Use these standard descriptions in requirement-backed requests sent through Figma MCP.

---

## 1. Grid & Page Framework

Always specify the device and screen width to anchor the layout:
*   **Desktop:** *"Design a 1440px desktop web application screen with a clean modern layout and standard 8px grid alignment."*
*   **Mobile iOS:** *"Design a mobile screen wireframe for iPhone 15 Pro, using a standard single-column layout with 16px side margins."*
*   **Tablet:** *"Design a tablet layout in landscape mode (1024px width) with double-column layout."*

---

## 2. Visual Layout Zones

Describe the screen by dividing it into distinct areas (zones). Specify the location and alignment of each zone:

### Sidebar Navigation Layout
*   *"Use a split layout: a narrow left navigation sidebar (250px width) and a spacious main content workspace on the right."*
*   *"The sidebar must contain a top logo, a vertical list of menu items (with generic icons and text labels), and a user profile box at the bottom."*

### Top Header & Main Body Layout
*   *"Include a sticky top header (80px height) featuring a logo on the left, a central search bar, and user settings actions on the right."*
*   *"Below the header, the main body is split into a left column (2/3 width) for the primary details and a right sidebar (1/3 width) for secondary metadata."*

### Multi-Step Wizard Layout
*   *"At the top of the main screen, place a horizontal step progress bar showing 3 steps: 1. Account, 2. Payment, 3. Success."*
*   *"Below the steps, display a centered card panel containing the active form step, and a footer bar at the bottom containing 'Back' and 'Next' buttons."*
