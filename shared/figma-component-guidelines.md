# Figma Make: Component Guidelines

Use these mappings to translate functional requirements into clean Figma Make component prompt descriptions.

---

## 1. Input Fields & Forms

Instruct the AI using explicit states and placeholders:
*   **Text Inputs:** *"A text input field for 'Full Name' with a placeholder 'John Doe' and a tiny 'Required' label above it."*
*   **Dropdowns/Selectors:** *"A dropdown field labeled 'Select Country' showing the default selected option 'United States'."*
*   **Checkboxes/Switches:** *"A small checkbox element labeled 'I agree to the terms of service' showing an active checked state."*
*   **Date Pickers:** *"A date input field for 'Start Date' with a calendar icon on the right and helper text 'Format: MM/DD/YYYY'."*

---

## 2. Lists & Data Visualizations

Ensure structures are explicit:
*   **Tables:** *"A data table with 4 columns: 'Invoice ID', 'Date', 'Amount', 'Status'. Populate it with 3 rows of realistic billing data. The last column should display status pill badges."*
*   **Pill Badges:** *"Use pill badges to represent statuses: green for 'Paid', orange for 'Pending', and red for 'Overdue'."*
*   **Metric Cards:** *"At the top, display 3 horizontal metric cards: 1. 'Total Sales' showing '$12,450' with a small green uptrend arrow, 2. 'Active Users' showing '1,200', 3. 'Bounce Rate' showing '2.4%'."*

---

## 3. Navigation & Actions

Standardize button weights and visual hierarchies:
*   **Primary Actions:** *"A prominent primary blue button with text 'Submit Application' placed on the bottom right."*
*   **Secondary Actions:** *"A secondary neutral outline button labeled 'Cancel' placed immediately to the left of the primary button."*
*   **Icon Buttons:** *"A small square button containing a trash can icon (for delete action) placed on the far right of the list item."*
