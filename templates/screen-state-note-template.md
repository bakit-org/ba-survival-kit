# Khung ghi chú trạng thái màn hình (Screen State Note Template)

## Màn hình (Screen)

## Trạng thái (State)

- Mặc định (Default)
- Lỗi (Error)
- Thành công (Success)
- Đang tải (Loading)
- Không khả dụng (Unavailable)

## Điều kiện kích hoạt (Trigger)

[Ví dụ: Người dùng bấm xác nhận nhưng lỗi cổng thanh toán]

## Giao diện người dùng thấy (What user sees)

- [Ví dụ: Nút bấm bị vô hiệu hóa, Hiển thị biểu tượng cảnh báo đỏ]

## Hành động tiếp theo có thể thực hiện (What user can do next)

- [Ví dụ: Bấm nút 'Thử lại' hoặc Quay lại giỏ hàng]

## Thông báo hiển thị (Message shown)

- [Ví dụ: 'Thanh toán gián đoạn, vui lòng thử lại sau.']
