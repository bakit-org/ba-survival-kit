# Codebase Summary

This document details the directories and key files present in the refactored workspace.

## Directory Structure

- **`.agents/`**: Contains the local sync of workspace skills loaded by the Antigravity agent.
- **`docs/`**: Holds architecture guidelines, coding standards, and best practices.
- **`resources/`**: Student practice materials organized by course modules (Module 1 to 8).
- **`shared/`**: Contains shared layout guidelines, component definitions, and quality checklists.
- **`skills/`**: The catalog of 20 course-aligned skills.
- **`templates/`**: Standard Markdown templates used by the generator skills.
- **`scripts/`**: Setup, installation, and quality validation scripts.
