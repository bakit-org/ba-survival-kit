# Figma Make Best Practices for Business Analysts

This guide provides guidelines and best practices for BAs using AI-generated screen prompts (created by `ba-generate-srs`) with **Figma Make Designs (First Draft)** to generate wireframes.

---

## 1. How it Works

The SRS skill breaks down requirements into individual screen files under `srs-screens/`. Each file contains a copy-pasteable **Figma Make Prompt** block.

1. Generate the SRS using the `ba-generate-srs` skill.
2. Open your Figma design file.
3. Open the **Actions** menu (the star icon in the toolbar) and select **First Draft** (Figma Make).
4. Copy the prompt block from the screen markdown file and paste it into the Figma prompt input field.
5. Click **Generate** to get the initial layout wireframe.

---

## 2. Prompt Structure Best Practices

The prompts generated by the BA kit follow a strict structure for maximum fidelity:

* **Role & App Category:** Tells Figma AI what the application does (e.g., "A dashboard for a B2B SaaS analytics tool").
* **Structural Layout:** Specifies columns, headers, sidebars, and grid alignments.
* **Component List:** Enforces precise component terminology (e.g., "Text Input", "Dropdown", "Data Table", "Primary Button", "Tab list").
* **Copywriting:** Includes exact labels and mock values to avoid generic text placeholders.
* **Theme Styling:** Adds indications for theme and styling constraints (e.g., light theme, minimal borders, accent colors).

---

## 3. Iterative Design Refinement in Figma

Figma AI excels at iterative changes. Do not expect the first draft to be 100% perfect. Refine the generated draft using these prompts inside the Figma AI pane:

### Modifying Layout & Components
* **Add a component:** *"Add a secondary 'Export PDF' button next to the 'Save' button."*
* **Change placement:** *"Move the search bar to the center of the top header."*
* **Modify lists/tables:** *"Add a new column 'Total Cost' to the inventory table."*

### Adjusting Visual Style & Theme
* **Change theme:** *"Convert this frame to dark mode with a dark gray background."*
* **Modify borders/corners:** *"Make all form inputs have sharp 4px corners and subtle gray borders."*
* **Tweak spacing:** *"Increase the padding inside cards to 24px and increase spacing between fields."*

---

## 4. Troubleshooting Common Issues

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **Layout is disorganized / overlapping** | Too many elements in a single prompt block. | Ask Figma AI to clean it up: *"Clean up the alignment and place all elements on an 8px grid."* or simplify the prompt and add elements incrementally. |
| **Model ignores specific requirements** | Specific or non-standard components are requested. | Use standard Figma UI component names. Avoid custom/private UI library names in the prompt; swap them manually in Figma after generation. |
| **Components look like generic shapes** | Figma AI couldn't map the component name. | Highlight the frame and ask: *"Render the 'Status' selector as a standard dropdown field."* |
