# Project Overview & Product Design Reference (PDR)

This repository hosts the **BA Personal Survival Kit**, refactored to align with the curriculum of the course: **"AI Agent for IT Business Analyst with Antigravity"**. 

## Objective
The primary goal is to provide learners (fresher/junior BAs, career changers) with a set of pre-built, production-ready AI agent skills that automate the generation of key BA deliverables using **Markdown** formatting and **Figma MCP** wireframing techniques.

## Scope of Skills Pack
The kit consists of 20 distinct skills grouped into 6 logical categories matching the course module sequence:
1. **Notes & Briefs:** Structuring unstructured inputs into formatted notes.
2. **Wireframes:** Generating screen-by-screen layouts and transitions.
3. **Screen Specs:** Writing detailed system validations and behaviors.
4. **Diagrams:** Auto-generating Mermaid and ASCII flowcharts.
5. **Backlog Stories:** Generating use cases, Gherkin user stories, and acceptance criteria.
6. **QA & Packaging:** Writing test scenarios and consolidating index packs.

## Core Design Principles
- **BA-First Focus:** Starts with business problem logic, avoiding technical developer complexities.
- **Markdown-Native Workflow:** Formats all outputs in clean, transportable Markdown.
- **Review Mindset:** Promotes the "AI Drafts, BA Reviews, BA Owns" workflow.
